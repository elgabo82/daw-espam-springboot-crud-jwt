# Spring Boot REST API

## Description
Backend application developed using Spring Boot to manage structured data and business logic through RESTful services.

## Technologies
- Java
- Spring Boot
- MySQL / MariaDB
- Maven

## Features
- REST API endpoints
- CRUD operations
- Input validation
- Exception handling
- Layered architecture

## How to run
1. Clone the repository
2. Configure database connection
3. Run the application using Maven or IDE

## Purpose
This project demonstrates backend development skills and API design using Java and Spring Boot.
